# Zankai Agents project workflow

Read .team/PROJECT.md, .team/ARCHITECTURE.md and your assigned role/task before changing code.
Use npm. The coordinator plans tasks and maintains .team/BOARD.md. The human dispatches specialists.

Use separate Git worktrees for parallel implementation. QA verifies integrated work before completion.
